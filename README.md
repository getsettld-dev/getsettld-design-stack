# getSettld Design Stack

Curated Claude Code marketplace bundling design, UI/UX, accessibility, and animation skills for getSettld and related projects.

## Install

In Claude Code:

    /plugin marketplace add getsettld-dev/getsettld-design-stack
    /plugin

Then install plugins from the getsettld-design marketplace tab.

## Plugins included

- frontend-design — Aesthetic direction (Anthropic)
- web-artifacts-builder — React + Tailwind artifacts (Anthropic)
- canvas-design — Visual layouts (Anthropic)
- brand-guidelines — Brand consistency (Anthropic)
- ui-ux-pro-max — Design system database (67 styles, 96 palettes)
- web-design-guidelines — Vercel UI/UX quality gate
- web-accessibility — WCAG 2.2 AA audit
- shadcn-ui — Component management
- ui-animation — Motion design
- taste-skill — Distinctive aesthetics
- claude-designer-toolkit — Style toolkit
